## ⚡ 快速开始

<div align="center">

[![Node.js](https://img.shields.io/badge/Node.js-18+-339933?style=for-the-badge&logo=nodedotjs&logoColor=white)](https://nodejs.org/)

</div>

### 1️⃣ 克隆项目

```bash
git clone https://github.com/Jvxi/InkField-frontend.git
cd InkField-frontend
```

### 2️⃣ 安装依赖

```bash
npm install
```

### 3️⃣ 配置环境变量

创建 `.env.local` 文件：

```env
VITE_API_BASE_URL=http://localhost:4000/api
```

### 4️⃣ 启动开发服务器

```bash
npm run dev
```

<div align="center">

🎉 访问 **http://localhost:5173** 开始使用

</div>

### 5️⃣ 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist/` 目录。

## 🌟 功能详解

<details>
<summary><b>📝 书籍管理</b></summary>

<br/>

- 多书籍项目管理
- 书籍信息配置（类型、平台、基调）
- 书籍导入导出
- 书籍切换器

</details>

<details>
<summary><b>📋 大纲编辑</b></summary>

<br/>

- 可视化大纲树
- 拖拽排序
- 节点展开/折叠
- 大纲时间线视图

</details>

<details>
<summary><b>👤 角色管理</b></summary>

<br/>

- 角色卡片展示
- 角色关系图谱
- 角色详情编辑
- 角色导入

</details>

<details>
<summary><b>✍️ 章节写作</b></summary>

<br/>

- 流式 AI 生成
- 实时预览
- 中途取消生成
- 合规校验反馈

</details>
