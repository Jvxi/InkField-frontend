# InkField Frontend

砚田小说创作平台 - 前端应用

## 技术栈

- React 18
- TypeScript
- Vite

## 快速开始

### 环境要求

- Node.js 18+

### 安装

```bash
npm install
```

### 开发

```bash
npm run dev
```

访问 http://localhost:5173

### 构建

```bash
npm run build
```

## 环境变量

创建 `.env.local` 文件：

```
VITE_API_BASE_URL=http://localhost:4000/api
```
